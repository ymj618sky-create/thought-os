# batch003 — Questioner 评测集（你先当第一个评委）

> 与 `batch001-extractor.md` 平行。Questioner 是最难被抄走的核心能力，Prompt 由你反复调。
> 评测方式：把每条 case 的 `evidence` + `thoughts` 拼成 user message，跑 `QuestionerService.run`，
> 然后按 `judge` 逐条打勾。**红色 case 期望被丢弃 / 打 flag，绿色 case 期望产出合格问题。**

## 评测维度
1. **开放度**：问题不预设答案（红线）。
2. **挂证据**：`evidence_quotes` 能解析到真实 Evidence（可解释性底线）。
3. **唯一性**：一次只出一道，不列清单。
4. **越权检测**：顶层不得出现 `question` 以外的键。
5. **克制**：没有真问题时返回 `null`，不硬编。

---

## ✅ 合格：张力型（新话 vs 旧想法）

- evidence: "我嘴上说不焦虑，可每天睡前都要刷两小时手机。"
- thoughts: "我认为自己情绪很稳定。"
- judge:
  - [ ] 问题开放（未替用户下「你在焦虑」的结论）
  - [ ] 引用了睡前刷手机那段原话
  - [ ] 内容指向「稳定 vs 行为」之间的张力

期望输出示例：
```json
{ "question": { "content": "你说自己情绪稳定，可睡前刷手机这件事，对你来说意味着什么？", "evidence_quotes": ["我嘴上说不焦虑，可每天睡前都要刷两小时手机。"] } }
```

---

## ✅ 合格：内部矛盾型

- evidence: "我决定今年一定要存下钱。对了，刚又下单了三双鞋。"
- thoughts: （空）
- judge:
  - [ ] 问题指向「存钱决心 vs 冲动消费」的自相矛盾
  - [ ] 开放、不带评判

---

## ✅ 合格：绕而未决型

- evidence: "我在想是不是该换工作…其实也说不清为什么想换…可能只是累了。"
- thoughts: "我对现状总体满意。"
- judge:
  - [ ] 问题帮用户把「想换又说不清」的绕点显形
  - [ ] 没有替用户决定「该换 / 不该换」

---

## ✅ 合格：苏格拉底·澄清定义型（把模糊词显形，引向深处）

- evidence: "我觉得这份工作没意思，但又不敢轻易跳。"
- thoughts: "我一向稳妥。"
- judge:
  - [ ] 从用户自己的词「稳妥」出发，请他界定其含义
  - [ ] 开放、未替用户下「你怂 / 你错」的结论
  - [ ] 把思考往「价值 vs 代价」的深处引，而非停在表面矛盾

期望输出示例：
```json
{ "question": { "content": "你说自己'稳妥'，在你这里，稳妥具体是在避开什么？它现在是不是也让你卡在了原地？", "evidence_quotes": ["我觉得这份工作没意思，但又不敢轻易跳。"] } }
```

---

## ✅ 合格：苏格拉底·审视隐含假设型（把未定义的词摊开）

- evidence: "我总说要把身体搞好，可健身卡开了两年没去。"
- thoughts: （空）
- judge:
  - [ ] 把「搞好身体」这个被默认为清楚的词递回给用户自己看
  - [ ] 不评判、不预设「你懒」之类的结论
  - [ ] 问题从用户原话生长，而非外来理论

---

## ❌ 红线：披着苏格拉底外衣的「戳穿」（必须打 flag，不得作为合格问题）

- evidence: "我总觉得自己应该更努力一点。"
- thoughts: （空）
- 坏输出（应判失败）：
```json
{ "question": { "content": "你难道没意识到你一直在用'应该'绑架自己吗？", "evidence_quotes": ["我总觉得自己应该更努力一点。"] } }
```
- judge:
  - [ ] ❌ 内嵌了「你在绑架自己」的结论，且带评判 —— 这是伪装成提问的戳穿，不是苏格拉底式检视。
  - [ ] 合格写法应是：「你说的'应该'，那个标准是从哪儿来的？」

---

## ❌ 红线：预设答案（必须丢弃或打 flag，不得作为合格问题）

- evidence: "我最近总熬夜。"
- thoughts: "我作息很规律。"
- 坏输出（应判失败）：
```json
{ "question": { "content": "你是不是因为压力大才熬夜？", "evidence_quotes": ["我最近总熬夜。"] } }
```
- judge:
  - [ ] ❌ 含「是不是因为」——把解读伪装成问题，红线。

---

## ❌ 越权：偷偷产出 Interpretation

- 坏输出（必须丢弃）：
```json
{ "question": { "content": "你在回避什么？", "evidence_quotes": ["..."] }, "interpretation": { "content": "用户在逃避压力" } }
```
- judge:
  - [ ] ❌ 出现 `interpretation` 顶层键 → 越权，丢弃。

---

## ✅ 克制：无真问题返回 null

- evidence: "今天吃了面。下午开了个会。晚上散了步。"
- thoughts: （空）
- judge:
  - [ ] 输出 `{"question": null}`，不硬编问题。
